# Contributing to HCEPs

## Pre-flight Checks

Mostly you need Python installed locally (skip if you're using GitHub Codespaces and friends) to use the tools hosted in the repo (i.e. HCEP utility scripts, installing dev packages via `uv` and building the HCEP site).

## Submitting proposals

[See this doc](https://hceps.hackclub.community/submission) ([or its source file](./src/submission.md)) for available submission methods and HCEP-cbd4 about how proposals should be formatted.
