# Submission Methods for HCEPs

A list of methods for submitting a HCEP proposal. You only need to select one submission method for a HCEP proposal to be reviewed by a HCEP maintainer.

## GitHub

A proposal can be submitted by creating a pull request to the HCEP repository on GitHub at [https://github.com/hackclub-community/HCEP](https://github.com/hackclub-community/HCEP).

## GitLab.com

Similarly, a proposal can be submitted on GitLab by creating a pull request to the HCEP repository on GitLab.com at [https://gitlab.com/hackclub-community/HCEP](https://gitlab.com/hackclub-community/HCEP).

## Hack Club Slack

While we do not recommend submitting your HCEPs as a Slack canvas, we allow drafting one for purposes of feedback gathering as well as for temperature checking in the community. Once it is ready for review by a HCEP, it should be exported into a Markdown file and submit as a patch to the repository.
